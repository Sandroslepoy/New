# Новини Онлайн

Мінімалістичний сайт‑агрегатор новин, який автоматично підтягує свіжі статті з інтернету через RSS‑джерела.  
Проект створений для швидкого розгортання на **GitHub Pages**.

## 🚀 Функціонал
- Автоматичне завантаження новин з кількох RSS‑джерел (Україна, світ, технології).
- Мінімалістичний дизайн: простота та швидкість.
- Кнопки «Поділитися» у Facebook, Twitter, Telegram.
- Легке розгортання на GitHub Pages.

## 📑 Структура
- `index.html` — головна сторінка.
- `style.css` — стилі.
- `script.js` — логіка завантаження новин.
